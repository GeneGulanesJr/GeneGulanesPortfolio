A persistent, local-first AI memory layer for coding agents — SQLite-backed with zero cloud dependencies. Provides automatic context injection, decision detection, code analysis (call graphs, dead code, complexity), doc indexing, and cross-session memory continuity. Plugs into Pi, Claude Code, Hermes, and any MCP-compatible agent.
