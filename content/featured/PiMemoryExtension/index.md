A persistent memory layer for the Pi coding agent — SQLite-backed with zero cloud dependencies. Provides automatic context injection, decision detection, code analysis (call graphs, dead code, complexity), doc indexing, and cross-session memory continuity. Ships with 244 tests and powers the memory-code and memory-doc analysis tools.
